# Git State Compass

[English](README.en.md)

中文别名：Git 状态罗盘

Git State Compass 是一个面向 GitHub 新手的本地 Git 状态罗盘。它把当前分支、远端跟踪分支、工作区状态和常见 GitHub 操作放在一起解释，并给出一条不依赖大模型的下一步建议。

## 它解决什么问题？

当你不知道“我现在在哪个分支”“本地和远端谁更新”“这个 PR 能不能提”时，工具会先读取本地仓库事实，再用确定性规则生成建议。它不会凭空猜测，也不会替你执行危险的 Git 或 GitHub 写操作。

## 当前版本能做什么？

- 查看当前分支、分支拓扑和远端跟踪关系
- 识别工作区是否有未提交修改
- 分析“准备提交 PR”“判断合并准备情况”“了解远端变化”等目标
- 用新手能看懂的方式说明事实、风险、下一步和建议失效条件
- 通过本地浏览器原型查看可视化结果
- 在 Windows 文件夹弹窗中选择目录；选中外层资料夹时，有限范围查找附近的有效仓库
- 显示所选工作目录、当前提交、同仓库 worktree 数量，以及相对本地主线记录的位置

当前版本是本地浏览器原型，读取本地 Git，不调用大模型，不联网执行 GitHub 操作，也不是正式桌面安装包。页面只展示读取那一刻的状态；仓库有变化时需要重新读取。Windows x64 便携测试版已可在本地构建，普通测试者不需要安装 Node.js。

## 快速开始

从源码运行需要 Node.js 22 或更高版本，以及 Git。便携测试版只需电脑已有 Git，参见人工测试说明。

```text
npm ci
npm test
npm run inspect -- <你的本地仓库路径>
npm run web
```

运行 `npm run web` 后，终端会显示本次随机分配的本机地址。在浏览器打开它，点击“选择文件夹”，或手动输入路径。关闭终端中的服务后，该地址随即失效。工具只读取仓库状态；提交、合并、推送和 PR 操作仍由你确认后手动完成。

在安装 Node.js 24 的 Windows x64 开发电脑上运行 `npm run build:portable`，可生成本地测试用 EXE。产物位于被 Git 忽略的 `output/portable/`，尚未公开发布。源码运行与便携版构建的环境要求不同，详见[换机与开发环境恢复](docs/development.md)。

## 给新手的理解方式

可以把它理解成汽车仪表盘：它告诉你当前在哪条“路”（分支）、车里还有没有未保存的东西（工作区修改）、远处的路况是什么（远端跟踪状态），然后告诉你下一步应该先检查什么。它不会替你踩油门。
